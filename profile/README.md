# axflower

axflower 专注于离线中文输入与词库建设，希望让中文输入更简单，也让输入内容留在用户自己的设备上。

- **[flower](https://github.com/axflower/flower)**：使用 Rust 开发的 Windows 拼音输入法，支持全拼、简拼、混拼和本地选词记忆，无需账号，输入过程离线运行。
- **[flower-dict](https://github.com/axflower/flower-dict)**：独立维护的中文拼音词库，提供静态数据与 Rust 接口，可供其他输入法、检索和文本工具复用。

欢迎参与代码开发、词库完善和兼容性反馈。
